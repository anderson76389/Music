- **Son/Vidéo toujours visible** : les boutons apparaissent immédiatement sur chaque musique dès que le mode est activé. La vidéo reste inaccessible si aucun clip jouable n'est disponible.
- **Téléchargements M4A/AAC** : uniquement deux formats d'export, avec le meilleur flux AAC natif disponible et M4A recommandé pour la compatibilité.
- **Mises à jour plus claires** : le pop-up présente uniquement les nouveautés de cette version, dans une liste lisible. Les anciennes notes ne sont plus reprises automatiquement.
