SERVEUR D’ÉCOUTE PARTAGÉE MAKOFF MUSIC

Le serveur et son protocole sont intégralement présents dans ce dossier.
Aucun sous-module ni dépôt Metrolist n’est téléchargé pour la construction.
Ce serveur n’est PAS déjà hébergé par GitHub Actions ou GitHub Pages.

Sur un serveur Linux avec Docker Compose et un domaine pointant vers son adresse :
  export MUSIC_DOMAIN=musique.votre-domaine.fr
  docker compose up -d --build
Les ports 80 et 443 doivent être accessibles pour HTTPS et le certificat TLS.
Les données des salons sont conservées dans le volume rooms.

Dans MAKOFF Music : Paramètres > Écoute partagée > Serveur personnalisé :
  wss://musique.votre-domaine.fr/ws
Configurer la même adresse sur les appareils des participants, puis créer ou
rejoindre un salon. L’application n’utilise plus le serveur partagé de Metrolist.

Sans hébergement de ce serveur, l’écoute synchronisée entre appareils n’est pas
opérationnelle. La lecture, la recherche et les téléchargements n’en dépendent pas.
