Identifiant Android : fr.makoff.music ; tests : fr.makoff.music.debug.
Dépôt, sources et mises à jour : https://github.com/anderson76389/Music
Logo d'origine conservé localement et contrôlé par 31 empreintes SHA-256.
Moteur InnerTubeX inclus dans vendor ; configuration distante désactivée,
anciennes adresses Faraday supprimées. Aucun service Metrolist actif connu
n'est nécessaire dans la configuration auditée.

Les fonctions de salons et de traduction IA ont été retirées : interfaces,
clients réseau, réglages, ressources multilingues, serveur, protocole et
outillage Protobuf. Discord et Last.fm restent retirés.
Les champs historiques de traduction de la base locale sont conservés pour
ouvrir les sauvegardes/installations existantes sans modifier le schéma ;
ils ne sont plus utilisés par une fonction de traduction ou un service IA.

Dépendances en ligne restantes : YouTube/Google, fournisseurs de paroles,
Shazam, AutoEQ officiel, Return YouTube Dislike et GitHub. Google Cast utilise
le SDK Google dans l'APK universel publié. Les bibliothèques et outils de
construction Android/Maven/Gradle/JitPack restent extérieurs ; ils ne sont pas
intégralement archivés dans ce dépôt. Voir VERIFICATION-FONCTIONS.txt.

La disparition du dépôt d'origine ne retire pas les sources embarquées.
Ce contrôle du code ne garantit pas tous les scénarios réseau ni la pérennité
des services tiers. Les versions de test ont une signature temporaire ; une
clé privée durable est nécessaire pour les futures versions stables.
