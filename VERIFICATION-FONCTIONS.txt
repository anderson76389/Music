METROLIST PERSONNEL — VÉRIFICATION DES FONCTIONS, 18 OCTOBRE 2026

Nom affiché rétabli à Metrolist ; identifiant et mises à jour du projet personnel
conservés. Les fonctions de salons et de traduction IA sont supprimées, ainsi
que leurs ressources et services. Le lecteur, les paroles originales et la
romanisation locale restent présents.

Les champs historiques de la base sont conservés pour la compatibilité des
données, sans service IA actif. Aucun schéma de base n'a été modifié.

FONCTIONS / DÉPENDANCES / PREUVES
- Interface et réglages : navigation Android automatisée dans les six catégories,
  bascule du fondu et ouverture de la qualité testées dans la dernière préversion.
  Ce test ne clique pas chaque combinaison de chaque réglage.
- Historique : chargement réel des Releases de ce GitHub testé sur émulateur.
- Lecture, recherche, comptes, playlists et bibliothèque en ligne : code présent,
  services Google/YouTube nécessaires. Connexion avec votre compte, synchronisation,
  lecture et enchaînements sur votre téléphone non validés intégralement.
- Téléchargement interne : fonction conservée. Changer la qualité ne supprime
  plus le fichier déjà téléchargé. Sa qualité reste celle du téléchargement.
- Export en dossier : moteur yt-dlp embarqué, distinct du téléchargement interne.
  Tests Android réussis sur AAC/M4A, Opus/WebM et WAV via serveur local : données
  identiques et codecs reconnus. L'essai YouTube anonyme de CI a été refusé par la vérification anti-robot ; aucun
  téléchargement YouTube authentifié de bout en bout n'est donc certifié ici.
- Qualité : HIGH par défaut ; formats disponibles selon le morceau, le compte
  et YouTube. Aucun FLAC créé et aucun débit de 256 kbit/s garanti pour tout titre.
  Voir QUALITE-AUDIO.txt.
- Paroles : fournisseurs tiers LRCLIB, KuGou, Paxsenix, BetterLyrics, Zemer,
  LyricsPlus. Leurs pannes, contenus manquants et limites ne sont pas maîtrisés.
- Égaliseur : code local ; AutoEQ dépend du dépôt officiel jaakkopasanen/AutoEq
  pour rechercher/télécharger les profils. Cache locale ensuite. Récupération
  corrigée pour refuser un index incomplet et fractionner les arbres tronqués.
  Import/application audibles sur votre casque non vérifiés ici.
- Reconnaissance : dépend de Shazam et du microphone, non validée sur téléphone.
- Cast, Bluetooth, Android Auto, widgets, écran verrouillé et gestion batterie :
  code présent ; nécessitent des essais avec le matériel et les permissions réels.
- Sauvegarde/restauration : code présent ; une restauration complète des données
  de votre appareil n'a pas été testée.
- Mise à jour automatique : désactivée dans les APK de test à signatures temporaires.
  Une clé stable privée et durable doit être configurée pour publier des versions
  stables pouvant se mettre à jour sans réinstallation. Ne pas désinstaller sans
  sauvegarde des données.

VALIDATION DE LA NOUVELLE RÉVISION
Compilation, tests et publication à confirmer dans GitHub Actions avant de
considérer la nouvelle préversion comme vérifiée.
